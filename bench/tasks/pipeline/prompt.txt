Our nightly job runs load.py to load events into the database, and sometimes it gets run twice or the file contains events we already loaded. That doubles our numbers. Also last week one broken line in the file made the whole load crash halfway, leaving half a file loaded. Make the loader safe: running it again should never create duplicates, a newer copy of an event with the same id should replace the old one, and bad lines should be skipped and counted rather than crashing. It should print how many were loaded and how many were skipped.
